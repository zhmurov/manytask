A few things to know

Before your
first assignment.

I'm a student. Where do I start?+

Open the Manytask instance and course link provided by your teacher. The student guide explains registration, repositories, submissions, and scores.

Can I use Manytask for a language other than Python?+

Yes. Manytask stores scores and course settings independently of the programming language. The checker runs the tools you configure in your course environment. See checker configuration.

Can we host it ourselves?+

Yes. Manytask is open source and can be deployed on your own infrastructure. The setup guide covers the services you need. SourceCraft and GitLab have different authentication and repository settings; see the deployment configurations.

How can I contribute?+

Explore the monorepo, pick an open issue, or join the community chat. The web app, checker, course template, and documentation live together.
