# Manytask interface assets

Snapshot of the Manytask style guide, updated November 10, 2026.

- `manytask-compact.svg` and `manytask-compact-dark.svg`: original Manytask
  symbol with the Montserrat wordmark, supplied as outlines. Symbol source:
  https://github.com/manytask/identity (MIT; see `licenses/Manytask-Logo-MIT.txt`).
- `fonts/`: Montserrat and Nunito Sans, Regular 400 and SemiBold 600 (SIL OFL
  1.1; full licenses in `licenses/`).

All assets are served locally. Font roles and interface colors are defined in
`../css/brand.css`.
